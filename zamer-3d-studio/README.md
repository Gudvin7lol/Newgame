# ZAMER 3D Studio 0.3 Native

Это отдельное Android-приложение на Godot 4.5.1. Оно не использует HTML, WebView, CDN или браузерный движок. Основная ветка и существующие сборки Замера не затрагиваются.

## Уже реализовано
- Сенсорное вращение камеры и масштабирование;
- Процедурные объёмные меши подушек дивана, отдельные подлокотники, декоративный кант, ножки;
- Тумба и стол как базовые параметрические модели;
- Изменение размеров в миллиметрах и параметра мягкости;
- Четыре процедурных цветных материала, студийный свет;
- Локальное сохранение проекта, PNG и GLB.

## Пока не реализовано
- Фотореалистичный high-poly диван с полноценной производственной деталировкой;
- Импорт внешних high-poly ресурсов, UV-редактор, полноценный mesh editing;
- Высококачественные normal/roughness maps, HDRI и path tracing;
- Системный Android-диалог выгрузки результата в публичную папку или отправки в другие приложения.

ВНИМАНИЕ: на текущем этапе PNG, GLB и проект сохраняются в приватное хранилище приложения (user://). Доступ через обычный файловый менеджер может отсутствовать, до реализации Android SAF экспорта.

## APK через GitHub Actions
Workflow расположен в .github/workflows/build-zamer-3d-studio.yml. После push в ветку zamer-3d-studio сборка запускается автоматически.
В репозитории открой Actions -> Build ZAMER 3D Studio Android -> последний успешный запуск -> Artifacts -> ZAMER-3D-Studio-Android-APK. Внутри ZIP находится debug APK для ARM64. Это тестовая подпись, не релиз для Google Play.
