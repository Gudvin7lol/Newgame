# Замер v0.9 Professional Alpha

Рабочая следующая версия приложения для обмера и проектирования квартир.

Ключевой фокус v0.9 alpha: геометрия, три слоя проекта, библиотека объектов, электрика, 3D-камера, 4K-экспорт и первый рабочий импорт планировки по фото.

Фото-скан в этой версии — масштабируемая подложка с калибровкой и ручной трассировкой. Автоматическое компьютерное распознавание стен и полноценная реконструкция 3D по видео остаются следующим этапом, чтобы не выдавать эксперимент за точный обмер.
