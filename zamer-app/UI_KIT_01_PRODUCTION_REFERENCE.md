# ZAMER — UI KIT 01 PRODUCTION REFERENCE

Статус: **актуальный обязательный визуальный источник истины**.

Этот документ фиксирует параметры из утверждённых пользователем изображений `UI KIT 01 — Production Spec`, `UI KIT 01 — Foundation & Common Components` и референса экрана `Главная`.

Если старый `MASTER_UI_SPEC.md` противоречит этому документу в вопросах визуала, размеров, палитры, компонентов или структуры Главной, **приоритет имеет этот документ**.

## 1. Базовый mobile reference

- дизайн-референс: `375 × 812 px`;
- сетка: 4 колонки;
- горизонтальные поля: `16 px`;
- рабочая ширина контента: `343 px`;
- адаптация выполняется пропорционально и по constraints, без растягивания компонентов «на глаз».

## 2. Spacing

Единственная шкала отступов:

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 px`

## 3. Палитра

Основные:

- Navy `#0B1F3B` — фон, шапки;
- Graphite `#1A2A3A` — панели;
- Dark Gray `#2C3B4A` — карточки / тёмные поверхности;
- Beige `#DBC3A5` — основной акцент;
- Cream `#F3E9D7` — светлые поверхности;
- White `#FFFFFF` — основной светлый текст и иконки.

Семантические:

- Success `#2EA043`;
- Warning `#FFB020`;
- Error `#FF4444`;
- Info `#3B82F6`.

Нейтральные:

- Gray 100 `#F5F7FA`;
- Gray 300 `#D1D5DE`;
- Gray 500 `#9AA4B2`;
- Gray 700 `#6B7280`.

## 5. Радиусы

`4 / 8 / 12 / 16 / 20 / 24 px`

Нельзя вводить дополнительные локальные радиусы без отдельного обоснования.

## 6. Базовые размеры компонентов

- верхний bar: `56 px`;
- bottom navigation: `72 px`;
- input/search: `56 px`;
- основная кнопка: `56 px`;
- card S: `80 px`;
- card M: `120 px`;
- минимальная touch area: `48 × 48 px`;
- icon button: `48 × 48 px`.

## 7. Состояния

Компоненты реализуют состояния:

- Default;
- Pressed;
- Selected;
- Disabled;
- Loading;
- Error;
- Success;
- Focused для input/dimension fields.

Focus border: `2 px` информационного/акцентного контура согласно production board.

## 8. Главная — обязательная композиция

Экран Главная переносится по утверждённому референсу без добавления новых секций.

Вертикальная структура:

1. top bar: `ЗАМЕР` + настройки;
2. search `Поиск проектов…`;
3. две action-card в один ряд:
   - `Новый проект`;
   - `Импорт плана`;
4. `Недавние проекты` + `Все ›`;
5. до четырёх компактных project cards;
6. `Шаблоны` + `Все ›`;
7. три template cards:
   - `Квартира`;
   - `Дом`;
   - `Коммерция`;
8. bottom navigation.

На полотне Главной запрещены:

- hero-card `Продолжить работу`;
- отдельный блок `Быстрые действия`;
- сетка из четырёх больших действий;
- любые дополнительные секции, которых нет в референсе.

Дополнительные действия уходят в Bottom Sheet / menu.

## 9. Bottom navigation Главной

В соответствии с актуальным production reference:

`Главная | Проекты | Каталог | Обучение | Ещё`

Эта навигация относится к верхнему уровню приложения.

Рабочие режимы проекта (`Замер / 3D / Оснащение / Развёртки`) остаются внутри открытого проекта и не смешиваются с home-level navigation.

## 10. Project card

Компактная карточка проекта:

- высота ориентирована на Card S `80 px`;
- preview слева;
- название;
- дата / вторичная строка;
- площадь;
- фото;
- overflow menu;
- radius `12 px`;
- тонкий dark border.

Не превращать project card в hero banner.

## 11. Bottom Sheet

Production reference использует светлую Cream-поверхность:

- верхние радиусы до `24 px`;
- строки действий по `56 px`;
- горизонтальные поля `16 px`;
- тёмный Navy-текст/иконки;
- drag handle сверху.

## 12. Component source of truth

Реализация:

- `lib/design_system/zamer_tokens.dart`;
- `lib/design_system/zamer_theme.dart`;
- shared-компоненты в `lib/design_system/`;
- production Главная: `lib/screens/home_production_screen.dart`.

Новые экраны должны использовать те же токены и компоненты. Нельзя заново подбирать «похожие» размеры или цвета.

## 13. Правило реализации

`Reference image → exact tokens → shared component → screen → CI → device check`

Не переходить к визуальному polish следующего экрана, пока базовые компоненты текущего экрана не совпадают с UI KIT 01 по структуре и размерам.
