# Zamer 1.5.5+46

Текущий этап ТЗ: точная 3D-раскладка пола, раздельная отделка сторон стен, светлый 3D-фон, аналоговый стик прогулки и расширенная библиотека локальных моделей. В каждой сборке присутствует один готовый тестовый проект.

# Замер — исходники версии 1.5.4 Materials / Lighting / Elevations

Версия 1.5.4 продолжает GPU-ветку приложения. Build 43 дополнительно исправляет видимость реального напольного покрытия и настенной плитки, совпадение координат оснащения между планом и 3D, синхронизацию светильников с электрическим планом и компоновку рабочего экрана развёрток.

В 1.5.4 материал пола и стен берётся из `RoomMaterialSettings`, учитываются направление укладки и размеры модулей. Для высококачественного экспорта используется отдельный PBR-профиль с AO, screen-space reflections, мягкими тенями, bloom, цветокоррекцией и auto exposure. Это честный realtime PBR-рендер; офлайн path tracing и более дорогой GI остаются целью 1.5.6.

Каталог содержит 63 локальные GLB-модели. Добавлена категория «Освещение» с люстрами, подвесами, потолочными светильниками, треком, бра и торшером. Каталожные объекты знают способ монтажа: напольный, настенный или потолочный. Светильники создают в GPU-сцене аналитический источник света.

Развёртки получили навигацию по стенам, сводку помещения/отделки, размерную цепочку проёмов и настенные каталожные объекты.

В рабочем контейнере ChatGPT Flutter/Dart SDK не установлен, поэтому исходник обязан пройти `flutter analyze`, headless-safe `flutter test` и Android release build в GitHub Actions через вложенный мобильный сборщик перед установкой на телефон.

## Предыдущий APK 1.3.0

Приложение для обмера, планировки, отделки и инженерной подготовки помещений. Проекты хранятся локально; переносимая ZIP-копия содержит фотографии комнат. Старые JSON-копии тоже импортируются.

## Интегрированная версия 1.2.0

- Проверка обмера показывает разрывы контура, расхождение контрольной длины с участками, отсутствие отступов проёмов, высот и диагоналей. Источник, автор, дата и история изменений размера сохраняются; расчётные размеры помечены в PDF. Размеры автоматически не исправляются.
- Свободная перегородка больше не образует острый вырез в комнате. Трассу трубы можно вести под 90°. Электроточка привязана к стороне стены; предметы проверяются на пересечение со стенами.
- Покрытие можно раскладывать с общей точкой отсчёта в выбранных комнатах. Для настенной плитки есть подбор подрезки. Исправлены порядок отрисовки предметов и ёлочка в 3D.
- Работы и материалы считаются отдельно; расценки работ редактируются, неизвестная цена показана явно. Смета экспортируется в CSV. Навигация собрана в четыре основных режима.
- ZIP-копия содержит фото комнат. После импорта они размещаются на новом устройстве. Самопроверка на телефоне включает расчёт, растеризацию покрытий и 3D, ZIP и PDF.

Исторический раздел ниже относится к 1.2/1.3. В 1.5 основной 3D уже переведён на GPU-сцену; видео-сканирование, Bluetooth, AR, облако и оплата по-прежнему не входят в этот этап. Тёплый пол рассчитывает длину и число контуров, но не выпускает монтажную схему петель. Проверка жестов и вида на реальном телефоне требует установки APK и записи экрана.

## Сборка и проверка

Требуются Flutter 3.47.5, Android SDK API 36 и JDK 17:

```sh
flutter pub get
flutter test
flutter build apk --release
```

Результат: `build/app/outputs/flutter-apk/app-release.apk`. Текущий Android-проект подписан временным ключом для альфы; для публикации нужен постоянный ключ и отдельная проверка магазина.

Для проверки на телефоне откройте главный экран проектов, нажмите значок проверки и «Запустить проверку». Скопируйте отчёт и приложите запись экрана жестов, раскладок, развёрток и 3D. Перед испытанием сохраните важный проект в ZIP.

Папка `third_party/file_picker` содержит пакет file_picker 11.0.3 с исправлением для Android Gradle Plugin 9.1 в текущем шаблоне Flutter (лицензия в пакете).
