# Электрика P4: читаемые кабельные трассы на плане и журнал

Основа: P3, ветка feature/zamer-electrical-routes-p3, черновик PR #39.

## Реализовано

- План отображает реальные 3D-трассы физически созданных кабелей как отдельный необязательный слой. Для каждого участка берутся непосредственно X/Y координаты сохранённых вершин, для вертикального участка Z отмечается кольцо на плане; высота не превращается в фиктивную длину по XY.
- Цвет трассы устойчиво относится к ID электрической цепи. Значки существующих электроточек, их размер и камера не меняются.
- Физические трассы и старые нарисованные линии скрыты при открытии по умолчанию, включаются отдельно. Старые линии не становятся кабелями и не участвуют в сумме.
- Сломанная или устаревшая трасса (например, сдвинутый щит, неполный маршрут, удалённый конечный прибор) не выводится как подтверждённый маршрут. В журнале ей присваивается явный статус ошибки.
- Журнал: группировка по стабильным идентификаторам цепей, маркировка кабеля, начало/конец, количество жил, длина 3D геометрии и отдельно вручную заданный запас.
- У журнала есть фильтр по цепи, который синхронно фильтрует отображение физических трасс на плане. Отдельное переключение старого чернового слоя не зависит от фильтра.
- Расчётная ведомость включает только явно построенные кабели. Один кабель на одной трассе учитывается один раз независимо от количества жил. Два разных кабеля на общей трассе считаются двумя отдельными кабелями по длине каждого.
- Критически важный UX: неизвестный запас не приравнивается к нулю, отсутствующие маршруты и неверные маршруты не приравниваются к нулевой длине. При наличии неизвестного вводится статус «Итоговая потребность неизвестна», а сумма известных длин отмечается только как неполная.
- Интерфейс мастера: в строке средств электрики кнопка кабельного журнала и видимости трасс, в слоях можно отдельно включить старые черновые линии.
- Данные журнала вычисляются, исходный FloorPlan не меняется. Переключение фильтра не создаёт undo/redo.

## Инженерные ограничения

Это не монтажный проект и не подтверждение соответствия требованиям безопасности. Значение геометрической длины берётся из вручную введённых вершин. Отсутствуют учёт конструктивных пересечений, допустимых трасс прокладки, ввода в коробки, радиусов изгиба, реальные кабельные марки/сечения и закупка по упаковкам. Отметка «обмерено» выбирается пользователем и не заменяет документально подтверждённый обмер.

Плановый геометрический редактор уже поддерживает вертикальные участки, но визуализация на виде сверху не заменяет стеновую развёртку и монтажный узел.

## Следующее инженерное направление

1. Отдельные развертки электрических кабельных трасс по стенам, отметки штроб и реальные вводы в устройства.
2. Геометрические предупреждения при пересечении проёмов и конструкций, без объявления автоматической нормативной проверки.
3. Определённая спецификация кабелей и изделий с паспортными данными и отдельными параметрами каждой марки.
4. Реальная компоновка щита и проверка защитных аппаратов по вводным данным и нормативному профилю; не по сумме ватт.
