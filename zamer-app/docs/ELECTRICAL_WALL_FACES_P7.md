# Электрика P7: стороны стены и расчётные чистовые поверхности

Основа: P6, PR #42.

## Реализация

- В PlanWall два независимых необязательных поля electricalFaceLeft и electricalFaceRight. Они соответствуют левой (+1) и правой (-1) сторонам при движении от начального узла стены к конечному.
- Каждое поле хранит отдельно введённую толщину отделки в мм, её источник (не подтверждён, проект, документ, введённый обмер) и примечание. Для старых проектов поля отсутствуют и считаются неизвестными. Явно записанные 0 мм не равны отсутствующему размеру.
- Расчётная чистовая плоскость находится на подписанном расстоянии +/- (толщина стенового ядра / 2 + толщина отделки) от оси стены. Расстояние центра электроточки до такой плоскости рассчитывается из мировой XY-геометрии; U от начала стены сохраняет прежнюю систему координат.
- Меню слоёв электрики открывает «Стороны и отделка стен»: выбрать стену, сторону, увидеть расчётное положение поверхности и перечень приборов на выбранной стороне, изменить/сбросить толщину отделки с указанием происхождения.
- Только назначенные на конкретную стену и выбранную сторону точки участвуют в ведомости. Для точки отдельно показывается действительность монтажной базы P1; неизвестная база остаётся видимым предупреждением.
- Редактор не передвигает существующие электроточки при смене толщины отделки и не меняет электросхему. Сохранение выполняется через контроллер экрана электрики с предварительной проверкой и единым шагом undo.
- Развёртка P6 умеет фильтровать точки по выбранной стороне, не меняя прежний режим по умолчанию, чтобы сохранить совместимость.
- Старые проекты читаются без миграции; PlanWall.copyWith, FloorPlan.toJson/fromJson/restoreFrom сохраняют новые независимые поля.

## Границы надёжности

Толщина стенового ядра берётся из существующего PlanWall.thicknessMm (может быть значением по умолчанию), поэтому даже источник отделки «обмер» НЕ подтверждает достоверность всей чистовой плоскости. Размеры показываются только как расчётные. Умолчания для отделки не вводятся.

При развороте начального и конечного узла лево/право меняются физическими местами. Для каждого сохранённого значения отделки записываются идентификаторы узлов ориентированной стены. При их изменении расчёт расстояния до прежней чистовой поверхности блокируется с предупреждением, пока пользователь явно не подтвердит новую сторону и значение. Старые данные без отметки ориентации не считаются подтверждёнными. Это предотвращает молчаливую подмену стороны помещения.

В P7 не добавлены физические подрозетники/коробки, штробы, проверка допустимости трасс, привязки к реальным лицевым углам и обмеренные базы полов. Линии физического кабеля P6 пока относятся к оси стены, а не автоматически к поверхности.
