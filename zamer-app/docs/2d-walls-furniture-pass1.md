# 2D: стены и мебель — первый проход

Основа: ветка `codex/zamer-1.5.7-147-measure-ux-snap-fan`, коммит `b43ae5d`.

В 2D используем нейтральный вид без добавляемых падающих теней. Стены
объединяются в сплошные тела внутри каждого проектного слоя; тонкий контур
проходит только по границе тела, без швов между сегментами. Ковры рисуются
под мебелью, стены — поверх пересекающей их мебели, подписи и размеры — сверху.
Сохранённая геометрия, размеры и порядок объектов в проекте не меняются.

Добавлены два отдельных изображения сверху: `sofa-3` и `bed-180`. Это новые
2D-иллюстрации, созданные imagegen, а не новые 3D-модели. Они используются
общим CAD-рендером в плане и каталоге. Их изображения занимают существующие
габариты объекта: для стандартных элементов — 2200×950 и 1800×2200 мм.
Прозрачные поля исключены через исходный прямоугольник изображения.

Исходные PNG хранятся без изменения пикселей. При загрузке ширина декодирования
ограничена 1024 и 768 пикселями: две текстуры занимают около 4.4 MiB.
Существующие атласы и векторные символы остаются резервом при ошибке загрузки.
Остальной каталог пока использует прежние изображения; некоторые из них
содержат запечённые детали освещения. Для единого качества их нужно постепенно
заменять такими же нейтральными видами сверху.

Полы в этом проходе не изменены. В проверочном плане используется существующая
нейтральная заливка, чтобы оценить стены и мебель отдельно от будущей работы
над материалами.

## Проверка

```sh
flutter test --dart-define=ZAMER_WRITE_PREVIEW=true \
  test/neutral_2d_rendering_test.dart \
  test/wall_geometry_controls_v138_test.dart \
  test/room_object_raster_order_test.dart \
  test/cad_visual_quality_test.dart \
  test/cad_precision_v143_test.dart
```

Проверяются непрерывность стыка с разной толщиной стен и направлением осей,
порядок ковра/мебели/стен, отсутствие добавляемых теней, габариты и центр
дивана при повороте, загрузка новых изображений и бюджет декодирования.
Превью `docs/previews/neutral-2d-pass1.png` формируется настоящим
`CadPlanPainterV3`, без отдельной имитации рендера. Специальный workflow
`Zamer 2D walls and furniture preview` сохраняет его как артефакт.

Локально Dart JIT в рабочей среде завершался до запуска тестов, поэтому
результат проверок следует подтверждать по GitHub CI. Это первый проход;
проверка APK на устройстве и обновление всего каталога ещё требуются.

## Направление для следующих предметов

Строгий вид сверху, один предмет на прозрачном фоне, нейтральные цвета,
детализация ткани и швов, без пола и внешней падающей тени. Первыми в этом
стиле нужны кресло, обеденная группа и корпусная мебель. Каждый вид проверять
в плане на светлом и тёмном фоне, при поворотах и на обычном масштабе телефона.
После согласования общего вида — материалы пола с реальными размерами доски
и плитки, направлением укладки и корректными переходами в дверных проёмах.
