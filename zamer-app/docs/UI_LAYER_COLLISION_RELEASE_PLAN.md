# ЗАМЕР: единый интерфейс, слои, коллизии, документация и запуск

Версия проекта: 1.5.7+137 (следующая после базовой +136). Эта документация — план реализации, а не обещание, что все нижеописанные функции уже существуют.

## Правило UI

Сохраняем один рабочий CAD-холст +136: ни «основного / продвинутого», ни второго редактора. Рабочее поле — главное. На верхнем поле холста остаются только «Слои», «Сетка», «Привязки»; инструменты построения — в одной прокручиваемой строке, второстепенные операции — в контекстном меню.

Каждая часто используемая команда должна быть найдена за 1–2 касания. Никакие изменения видимости не могут удалять элементы из FloorPlan или менять состав экспорта.

## +137: первая версия центра слоёв и проверок (реализовано в ветке)

Открывается через значок «Слои» на холсте. Три группы:

1. **Строительные стадии:** существующие / демонтаж / новые, уже существовавшие в +136.
2. **Категории:** покрытия пола, стены, двери и окна, мебель, сантехника, электрика, инженерные сети, конструкции, размеры, подписи помещений.
3. **Коллизии (2D):** пересечения стен без общего узла; объекты со стенами; объекты между собой; занятые дверные проходы.

Переключатели управляют **только видимостью на 2D-холсте**. Никакие элементы модели не удаляются, никакие параметры не меняются, PDF-экспорт не зависит от текущего фильтра.

Коллизии находят координаты через действующие MeasurementReviewService и SpaceCheckService. В режиме отображения соответствующей категории на плане рисуется знак «!», а список конфликтов открывается через кнопку «Ошибки». При нажатии на ошибку план центрируется на соответствующей точке.

Кабели и трубы рисуются схематическими линиями по имеющимся координатам и не являются результатом 3D-коллизионного анализа.

**Ограничения:** ещё нет точного 3D-clash-engine для инженерных сетей, проверки зон обслуживания сантехники и нормативных проходов для каждой модели, проверки реальной зоны открывания двери, поиска скрытых пересечений фурнитуры, уровней высот трасс. Текущая SpaceCheckService работает преимущественно с 2D-прямоугольниками и отсечением по высоте. Нельзя представлять зелёный статус как заключение экспертизы.

## +138: приоритет №1 — коллизии 2.0

- Отдельный набор проверок: инженерные трассы со стенами и проёмами, пересечения коммуникаций, зоны вокруг санитарных приборов, критические проходы.
- Для каждого результата: объект(ы), координаты, высоты/габариты, серьёзность, выбранная категория, объяснение и возможное действие.
- Подсветка проблемного объекта/трассы на том же холсте, фильтры по уровню серьёзности.
- Для сложных требований (ширина прохода, монтажные зазоры) параметризуемые пороги, по умолчанию лишь «рекомендации для проверки», не универсальные нормативы.
- Обновление после изменения геометрии и исключение снятых с проекта элементов.
- Smoke-тесты 2D + Android. Нельзя рисовать коллизию без координат или хранить фиктивные данные.

## +139: первый запуск и понятная навигация

Контекстное обучение (3–5 шагов) поверх рабочего холста, которое можно пропустить:
1. построить наружный контур;
2. замкнуть комнату и указать размер;
3. добавить проём и выбрать стену;
4. применить материал;
5. проверить план и сохранить/экспортировать.

Каждый шаг ведёт к реально существующей кнопке, а не к статичной картинке. Для пустого проекта — стартовые действия «Создать план» / «Импортировать». Подсказки для жестов краткие и закрываются одним касанием. Повторный запуск обучения — в «Помощь».

## +140: документация и спецификация

- Центр «Помощь» в профиле/проекте: быстрый поиск по инструментам; «Как построить стены», «Привязки», «Двери и окна», «Работа со слоями», «Коллизии», «Экспорт».
- Каталог операций с иконкой, названием, назначением, двумя примерами, ограничениями и точными единицами (мм, м², °).
- PDF-комплект: обмер, демонтаж, монтаж, электрика, инженерия, развёртки, спецификация материалов, атрибуты версии. Неподдерживаемые разделы остаются явно недоступными, не создаются пустые/ложные страницы.
- Источники точности измерений и предупреждение о проверке размеров на объекте.

## +141: системные состояния и безопасность данных

Пустой проект; загрузка/ошибка импорта; офлайн; файл повреждён/несовместим; autosave pending/completed/failed; конфликт версий, восстановление; истёкшие разрешения; недоступные внешние 3D-ассеты. Для каждого состояния: ясный текст без жаргона, повторить/отменить, сохранение локального состояния и диагностика. Строго никаких фиктивных «сохранено».

## Тарифы: отдельный продуктовый трек

Пока нет подтверждённой системы покупок, реальных прав доступа и проверенного биллинга, **нельзя показывать пользователю активный Pro или работающую подписку**. Перед выпуском тарифов нужны:
- матрица Free/Pro на основе реализованных возможностей;
- серверная проверка доступа, восстановление покупки и работа офлайн с ограниченным кэшем;
- Play Billing/легальные требования региона, тестовые покупки и отмены;
- сохранность и экспорт собственных проектов при окончании подписки;
- прозрачный экран стоимости, сроков и отмены, локализованный под платёжный регион.
