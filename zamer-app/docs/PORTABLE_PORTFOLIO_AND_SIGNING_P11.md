# ЗАМЕР P11: все проекты в один ZIP и постоянная подпись APK

## Резервная копия

Экран «Проекты» → «Ещё» → «Сохранить все проекты в ZIP».

Экспорт содержит все пользовательские проекты, этажи, геометрию, электрику, работы и фотографии. Демо-проект не включается. Система проверяет созданный архив перед открытием системного меню Android «Поделиться».

**Обязательно сохранить ZIP вне телефона** (например, облако, внешний накопитель, второй телефон). Нажатие «Поделиться» без сохранения не является резервным копированием.

Файл содержит фото и может содержать личные данные клиентов; он не зашифрован. Максимум 30 проектов и 160 МиБ; лимит не допускает незаметного пропуска проектов. При превышении лимита нужно экспортировать отдельные проекты через их меню.

Восстановление: «Проекты» → «Ещё» → «Восстановить проекты». Можно выбрать общий ZIP либо ZIP/JSON одного проекта. После подтверждения каждый проект импортируется с новым ID, без перезаписи существующих. Повреждённые вложения останавливают всю операцию; созданные во время неудачного импорта каталоги фото удаляются без повреждения старых файлов.

## Постоянная подпись APK

P9 и P10 были собраны с временными debug-ключами отдельных раннеров. Приложения с разными подписями не могут обновлять друг друга. Старые подписи изменить невозможно.

В P11 Gradle поддерживает постоянный keystore, переданный только через защищённые переменные GitHub Actions. Обычные PR-проверки НИКОГДА не получают секреты подписи и помечают тестовый APK как временно подписанный.

Для ручного запуска выпуска с постоянным ключом: GitHub Actions → Zamer Codex CI → Run workflow → stable_release=true. Секреты:
- ZAMER_RELEASE_KEYSTORE_BASE64: Base64 приватного JKS keystore.
- ZAMER_RELEASE_STORE_PASSWORD: пароль хранилища.
- ZAMER_RELEASE_KEY_ALIAS: имя ключа.
- ZAMER_RELEASE_KEY_PASSWORD: пароль ключа.
- ZAMER_RELEASE_CERT_SHA256: отпечаток SHA-256 сертификата подписи (64 шестнадцатеричных символа), полученный из **того же** постоянного JKS. CI сравнивает фактический сертификат собранного APK с этим закреплённым значением и отклоняет смену ключа.


Если хотя бы одного секрета нет, стабильная сборка завершится ошибкой и не подменится тестовым APK. Никогда не помещайте keystore, пароль или Base64-ключ в Git, общедоступные файлы и чаты. Сохраните офлайн резервную копию секретного ключа.

Артефакт сборки теперь содержит APK, SHA-256 и signature-mode.txt с режимом подписи. Версия P11 получила versionCode 156 вместо 155.

**Даже первый APK с постоянной подписью потребует разовой переустановки P9/P10.** Перед удалением старого приложения нужен экспорт и проверка внешнего ZIP.
