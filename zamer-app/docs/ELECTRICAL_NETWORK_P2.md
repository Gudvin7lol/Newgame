# Электрика P2: явный граф цепей и распределительных коробок

Основа: P1 (монтажные размеры, привязка точек, черновик PR #37).

## Первый срез

- FloorPlan имеет необязательное поле electricalNetwork версии 1, сохраняемое в JSON и undo/redo.
- Цепи: устойчивый ID, название, тип, необязательный ID щита-источника.
- Кабели: ID, ID цепи, две точные конечные точки, список жил и необязательный ID старой графической трассы.
- Жилы: отдельные ID внутри кабеля и назначение, по умолчанию «не назначено».
- Клеммы: конкретная РК, маркер клеммы и явно выбранный набор концов жил разных кабелей.
- В карточке распределительной коробки доступен отдельный экран «Кабели и клеммы»: мастер создаёт цепь, задаёт физический кабель между РК и выбранной точкой, вручную выбирает число жил и их назначения, затем формирует клемму из конкретных свободных концов двух или более кабелей. Отмена закрывает редактор без изменения FloorPlan. «Сохранить связи» проверяет граф и создаёт ровно один undo-шаг. Подключённые к графу точки нельзя удалять, пока существуют их связи.

## Непереговорные правила

1. Никаких электрических соединений по совпадению координат, пересечению линий или похожим названиям групп.
2. Старые значения ElectricalPoint.circuit и ElectricalRun не конвертируются автоматически. В старом проекте topology = null, а отсутствие данных показано явно.
3. Связь с нарисованной линией подтверждается лишь явным routeRunId и соответствием обоих её концов концам кабеля.
4. Одна жила не может быть назначена в две клеммы в одной коробке; смешение цепей и заявленных несовместимых ролей жил выдаёт ошибку.
5. Нет никаких обещаний электробезопасности, подборки автомата, корректности кабельной марки или рабочего монтажного проекта.
6. Вход/выход в панели коробки определяется лишь ручным направлением записи кабеля, а не током или фактическим подключением.

## Следующие срезы

1. Следующий шаг редактора коробки: каталоги клемм и типоразмеров, проверка вводов кабеля, маркировка концов на обоих устройствах, редактирование существующего кабеля без разрушения связей, редактирование цепи и удобный поиск по помещению.
2. Редактируемые 3D-маршруты в миллиметрах с горизонтальными и вертикальными сегментами, конструкцией прокладки, длиной и запасом.
3. Переход от текстовых групп к ID цепей с явной миграцией. Модули рамок как разные физические потребители.
4. Щит с геометрией корпуса, DIN-рейками, реальной шириной модулей, каталогом устройств и электрической схемой; без расчёта защиты по одному значению ватт.
5. Монтажные листы, кабельный журнал, таблицы распредкоробок, спецификация и журнал замечаний.

## Границы экрана редактирования

- Добавление цепи не назначает щит-источник, автомат или защиту.
- Выбор числа жил не определяет их назначение; все новые жилы создаются как неопределённые до ручного выбора L/N/PE и других функций.
- Для монтажных соединительных клемм в этом этапе допускаются концы минимум двух разных кабелей. Внутрикабельные и внутренние соединения механизмов потребуют самостоятельной модели.
- Если пользователь изменит уже назначенные функции жил и получит конфликт, сохранение блокируется; предупреждения о неопределённых функциях остаются видимыми.
- Отсутствие ошибок целостности не означает соответствия нормам или пригодности схемы для монтажа. Электрическая безопасность требует исходных данных и проверки квалифицированным специалистом.
- Исправлено переполнение выпадающих полей монтажных привязок на экранах небольшой ширины.
