# ZAMER New Materials SourcePack v3

Интегрирован пользовательский пакет source/reference-материалов v3.

Состав:
- стены: красный кирпич, гипсовая штукатурка, матовая краска;
- плитка: светлый бетон, светлый мрамор, светлое терраццо;
- ламинат: светлый дуб, тёплый орех, дымчатый дуб;
- для каждого ламината в исходном наборе предусмотрено 16 вариантов доски.

## Важно

`source_sheet.png` из исходного архива являются фотореалистичными референсными листами, а не отдельными runtime-картами 2048×2048. Их нельзя вырезать из презентационного листа и апскейлить до 2K: это даст размытые и пластиковые поверхности.

В версии 1.5.7+118 девять семейств подключены через стабильные production-ID к уже проверенным `runtime_v2` PBR-профилям. Это сохраняет Normal/Roughness/Height-деталь и совместимость со старыми проектами.

Размер доски/плитки, фаска, направление, шов и раскладка остаются процедурными в приложении. Когда будут готовы отдельные полноценные 2K BaseColor/Normal/Roughness/Height/AO экспорты из source pack, их можно заменить под теми же ID без миграции проектов.
